# 📌 우아한테크코스 출석

## ☑️ 구현할 기능 목록

### 🟤 프로그램 진행 관련
- 기능 선택 안내를 출력한다.
- 기능 번호를 입력받는다.
- 입력값을 검증한다
    - 올바르지 않은 입력을 할 경우 `IllegalArgumentException`을 발생시키고, `[ERROR]`로 시작하는 에러 메시지를 출력 후 애플리케이션을 종료시킨다.
- 해당 기능을 실행한다.
- Q(종료)를 입력하지 않는 한 해당 기능 실행 이후 기능 선택 안내, 입력, 검증, 기능 실행을 반복한다.

### 🟤️ 출석 확인 관련
- 닉네임 입력 안내 문구를 출력한다.
- 닉네임을 입력받는다.
- 등교 시간 입력 안내 문구를 출력한다.
- 등교 시간을 입력받는다.
- 출석 확인 안내를 출력한다. 
  - 이미 출석한 경우에는 수정 기능을 이용하도록 안내한다.

### 🟤 출석 수정 관련
- 닉네임 입력 안내 문구를 출력한다.
- 닉네임을 입력받는다.
- 출석을 수정할 날짜 입력 안내 문구를 출력한다.
- 출석을 수정할 날짜를 입력받는다.
- 변경할 시간 입력 안내 문구를 출력한다.
- 변경할 시간을 입력받는다.
- 출석 수정 후 변경 전과 변경 후의 출석 기록을 출력한다.

### 🟤 출석 기록 확인 관련
- 닉네임 입력 안내 문구를 출력한다.
- 닉네임을 입력받는다.
- 전날까지의 출석 기록을 출력한다.
- 출석/지각/결석 횟수를 출력한다.
- 제적/면담/경고 대상자 여부를 출력한다.

### 🟤 제적 위험자 확인 관련
- 제적 위험자 조회 결과를 출력한다.
  - 제적 대상자, 면담 대상자, 경고 대상자순으로 닉네임과 결석/지각 횟수, 제적/면담/경고 여부를 출력한다.
